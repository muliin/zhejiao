# 折角

> 它不讨好你。它只把你的话折一个角，然后让你自己起名字。

折角不是陪伴型 AI。它只做一件事：把你的一句话"折"一下，让你自己给那份感受命名。

## 它长什么样

```
你说一句
  → 它接住（1-2 句正常话）
  → 换位置（一幅有距离的画面 + 一件现实不可能、逻辑通顺的"跳"）
  → 点题（一句，把折角的落点说出来）
  → 递 2-3 个"名字"
  → 你选一个 / 自己起
  → 它追问"这个 X 一般什么时候最明显"
  → 你继续聊
  → 你按住"合上"，这张卡片才封存
```

一个真实例子：

> **你**：我妈又催婚，我挂了电话很愧疚。
>
> **它**：挂了电话之后那种沉，是真的沉，不用急着把它说成别的什么。
>
> 深夜街角那间电话亭还亮着，几个人靠在墙边等，不是等打电话，是等里面的人挂断。亭子外头搁着一壶茶和几只杯子，规矩是：谁挂断出来，就在亭门上敲一下，下一个进去前先给他倒一杯。那壶茶从来不见少，倒多少都还是满的，也没人看见是谁续的。
>
> 在这里，挂断不是罪，是这地方唯一认的"到过了"——你带来的那个"错"，在这儿连个登记的地方都没有。
>
> **候选名字**：`替她值的那班夜` `还在应答的那半截` `给没犯过的错画勾`

## 快速开始

需要 Python 3.12，**无 pip 依赖**（仅标准库）。

```bash
# 1. 设置 DeepSeek API Key
#    Windows PowerShell
$env:DEEPSEEK_API_KEY = "sk-xxx"
#    macOS / Linux
export DEEPSEEK_API_KEY="sk-xxx"

# 2. 启动
python server.py

# 3. 打开浏览器
#    http://127.0.0.1:8765/
```

没有设置环境变量时，会退回读 `折角.py` 里 `CRED` 指向的文件（默认是本机的 `C:\Users\<你>\.dsh\.credentials.yaml`，格式 `DEEPSEEK_API_KEY: sk-xxx`）。**换机器请优先用环境变量。**

## 五个位置

同一句话，五个位置给出**五个不同的结论**——不是五种说法同一个道理。

| 位置 | 让你看到什么 | 结论方向 |
|---|---|---|
| 镜子 | 自己正在做一件多余的事 | 执念 / 姿势 |
| 异乡客 | 你内疚的事在这里"无罪" | 规则错位 |
| 彼岸 | 两岸各过各的日子 | 界限 |
| 多年以后 | 老年的你回看此刻 | 时间 / 一个点 |
| 高处 | 把你缩成一个点 | 尺度 |

每个位置**只能去一次**，顺序由你决定。走过的留在刻度上，点"看对照"能看到五句结论并排。

## 设计上的硬约束

1. **不讨好、不站队、不评判、不分析、不解释、不诊断。**
2. **不替你命名**——只递候选，命名权归你。
3. **事实不编，隐喻可编**。前者是"你住在出租屋"（冒犯），后者是"你站在一个关口前"（一个看法）。
4. **必须有"一跳"**：画面里要有一件现实不可能、却逻辑通顺的事。没有这一跳，就只是给细节加滤镜。
5. **禁止毫米级特写**——要有距离的场景，不是慢动作。
6. **不记得你**。记忆只属于当前这张卡片，换一张卡就是重新认识。

## 关于记忆和合上

- **卡片内**：保留本次对话历史。
- **跨卡片**：不共享。它记得这张卡片里聊过什么，但不认得你这个人。
- **合上**：按住"合上"1.5 秒，这张卡片封存——可以回看，不能再续。不可逆由服务端强制（拒绝 open / reply / lens 并清空上下文），不是一句前端文案。

## 已知限制

- 首字延迟 5–10 秒（API 波动）。
- `loss` 与 `shame` 的情绪域判定边界偶有模糊。
- 本地单机应用，未做公网部署和多用户鉴权。
